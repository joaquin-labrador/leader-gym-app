## 🇪🇸 Descripción (Español)

**Leader Gym App** es una plataforma moderna y profesional de gestión para gimnasios, diseñada con una estética "Premium Dark & Gold". Esta aplicación frontend permite administrar socios, planes, cobros e historial de ingresos de manera eficiente y visualmente impactante.

### ✨ Características Principales
- **Gestión de Socios**: CRUD completo (Crear, Leer, Actualizar, Eliminar) con validaciones y campos personalizados como fecha de nacimiento y DNI.
- **Control de Planes**: Visualización y mapeo de planes (Mensual, Semanal, Diario, etc.) con precios actualizados.
- **Registro de Pagos**: Sistema de facturación integrado para registrar abonos de socios a sus respectivos planes.
- **Historial de Ingresos**: Registro detallado de accesos al gimnasio por DNI, con una interfaz limpia y profesional.
- **Diseño Premium**: Interfaz oscura con acentos dorados, micro-animaciones y componentes UX optimizados (como el selector de fecha personalizado).

### 🛠️ Tecnologías
- **Frontend**: React 18 + TypeScript.
- **Build Tool**: Vite.
- **Estilos**: Tailwind CSS 4.0.
- **Iconos**: Lucide React.
- **Notificaciones**: Sonner.
- **Gestión de Fechas**: React Datepicker + Date-fns.

## 🇺🇸 Description (English)

**Leader Gym App** is a modern and professional management platform for gyms, designed with a "Premium Dark & Gold" aesthetic. This frontend application enables efficient and visually stunning management of members, plans, payments, and check-in history.

### ✨ Key Features
- **Member Management**: Full CRUD operations (Create, Read, Update, Delete) with validations and custom fields like birth date and ID.
- **Plan Control**: Visualization and mapping of plans (Monthly, Weekly, Daily, etc.) with updated pricing.
- **Payment Registration**: Integrated billing system to register member payments for their respective plans.
- **Check-in History**: Detailed log of gym accesses by member ID, featuring a clean and professional interface.
- **Premium Design**: Dark mode interface with gold accents, micro-animations, and optimized UX components (such as a custom-styled date picker).

### 🛠️ Tech Stack
- **Frontend**: React 18 + TypeScript.
- **Build Tool**: Vite.
- **Styling**: Tailwind CSS 4.0.
- **Icons**: Lucide React.
- **Notifications**: Sonner.
- **Date Management**: React Datepicker + Date-fns.

## 🚀 Instalación y Configuración / Installation & Setup

### Requisitos / Prerequisites
- [Node.js](https://nodejs.org/) (v18 o superior)
- [npm](https://www.npmjs.com/)

### Pasos / Steps

1. **Clonar el repositorio / Clone the repository**
   ```bash
   git clone https://github.com/joaquin-labrador/leader-gym-app.git
   cd leader-gym-app
   ```

2. **Instalar dependencias / Install dependencies**
   ```bash
   npm install
   ```

3. **Configurar variables de entorno / Set up environment variables**
   Crea un archivo `.env` en la raíz (si es necesario) / Create a `.env` file in the root (if required).

4. **Ejecutar en desarrollo / Run in development mode**
   ```bash
   npm run dev
   ```
